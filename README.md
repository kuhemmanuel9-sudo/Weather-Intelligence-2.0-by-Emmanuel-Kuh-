# Weather Intelligence

Weather Intelligence is a live weather dashboard designed and developed by Emmanuel Kuh. It brings forecasts, maps, charts, weather alerts, favorite locations, city comparisons, and simple planning guidance into one clean web page.

This project was built as a portfolio piece to show front end development, API integration, data visualization, responsive design, and practical JavaScript organization.

## What It Does

Weather Intelligence lets users search worldwide for a country, city, town, village, island, district, or named place, then view current weather, check a 7 day forecast, compare cities, browse United States locations by state, and save favorite places in the browser.

The dashboard also includes weather analysis cards, rain and snow timing, pollutant readings, and fact-based voice briefings that turn raw forecast data into useful guidance for outdoor comfort, travel, running, air quality, solar conditions, frost, snow, and storm risk.

## Features

1. Live current weather
2. 7 day forecast
3. Hourly and daily charts
4. Interactive map
5. NOAA weather alerts for United States locations
6. Air quality data where available
7. Worldwide place search through live geocoding
8. Browse all United States states and major cities
9. Search for smaller towns, villages, communities, neighborhoods, islands, districts, and named places when available from the data source
10. Voice safety alerts for travel and outdoor risk
11. Safety timeline for the next few hours
12. Best outdoor time and safe window indicators
13. Rain timing timeline from forecast data
14. Snow timing timeline using short-term snowfall data
15. 15-minute precipitation and snowfall windows where the forecast model provides them
16. Executive weather summary banner
17. Decision scores for running, cycling, driving, beach, gardening, photography, stargazing, flight delay risk, heat, frost, snow travel, solar, and storms
18. Air quality dashboard with pollutant readings
19. Animated weather atmosphere based on the selected location
20. Use current location with browser permission
21. Compare two cities
22. Save favorite locations with local storage
23. Voice language choices with clear regional labels, including English, Asante Twi, Akuapem Twi, Spanish, Italian, French, Portuguese, German, Arabic, Hindi, Chinese, Japanese, Korean, and Swahili
24. Installed browser voice picker so users can choose the most natural native voice available on their device
25. Light and dark themes
26. Fahrenheit and Celsius support
27. Responsive layout for desktop and mobile

## Data Sources

Weather forecast data comes from Open Meteo.

Air quality data comes from Open Meteo Air Quality.

Weather alerts come from the National Weather Service for supported United States locations.

Map tiles come from OpenStreetMap contributors.

## Notes

This project runs fully in the browser. It does not use a backend, database, account system, or paid API key.

Some features depend on browser permissions or data availability. Current location requires the user to allow location access, voice briefings use the browser speech feature, worldwide place coverage depends on the geocoding provider, 15-minute snow and rain timing depends on the forecast model, and NOAA alerts are focused on United States locations. The app prepares more natural speech text for Asante Twi, Akuapem Twi, and other languages, then uses the closest installed browser voice; for true native Twi audio, the user's device or browser must have a Twi or Akan voice installed.
